# GINA-Power-Analysis
Simulation-based power analysis

## Files
- `GINA_mixed_model_power_RQ1.Rmd` — research question 1 (mechanisms)
- `GINA_mixed_model_power_RQ2.Rmd` — research question 2 (matching hypothesis)
- `*.html` — knitted reports including all results
- `*.rds` — stored simulation results (loading these avoids re-running
  the simulations, which take several hours)

## Requirements
R 4.x, packages: lme4, dplyr, tidyr, MASS, Matrix, ggplot2
